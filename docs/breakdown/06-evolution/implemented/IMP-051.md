# Set the read target resolver during the pipeline

**Question:** Should the read target resolver be set during the pipeline instead of where it is assigned today?

**Evidence:** Resolver installation moved out of executor constructors into the assembly path: `ExecutorBuilder` factories and `make_la2_stack` call `install_resolver()`/`install_flat_resolver()` (`executor_builder.cpp:32-90`, `la2_builder.cpp:148`), documented in `docs/development.md:181-195`.

**Change:** Design where the resolver is installed in the pipeline, then move resolver assignment to that point.

**Risk:** Unknown — resolver installation affects the whole read path; design-first is explicitly requested.

**Acceptance:** Resolved by `95e0c4a`: the read resolver is installed once at assembly via `install_resolver()`/`install_flat_resolver()`, not in executor constructors; installation is documented in `docs/development.md:181-195`.
