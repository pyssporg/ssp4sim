# UC-013: Inject a Direct Variable Override During Simulation

- **Actor:** user with a running simulation and knowledge of the target variable.
- **Goal:** "inject a fixed value override on a specified variable, immediately or at a scheduled future simulation time."
- **Outcome:** at the applied simulation time the override changes the configured side (input or output) of the target variable; that side records or passes on the overridden value, and the simulation continues without interruption.
- **Capability:** variable injection and scheduling (`CP-001`).
- **Status:** implemented on the C++ `Simulator` and the daemon; `set_override`, `clear_override`, and `y = k*x + m` behavior, including scheduled `at`, are available.
- **Satisfies:** `REQ-016`.
- **Strain:** the override is scoped to the configured side; it does not rewrite the model or promise a matching value on the opposite side.
