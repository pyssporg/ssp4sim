# UC-026: Control a Running Simulation from an External Process

- **Actor:** operator or automation script that controls a simulation it did not launch or embed.
- **Goal:** "control the running simulation and observe its progress from a separate local process."
- **Outcome:** lifecycle, speed, reset, checkpoint, and shutdown commands issued over the local socket reach the same engine; state, time, terminal, error, snapshot, and lifecycle events reach connected clients; no network listener is opened.
- **Capability:** local control daemon (`CP-001`).
- **Status:** implemented by `ssp4simd`, which serves newline-delimited JSON on a Unix domain socket with one active simulation and at most eight clients. Checkpointing (`snapshot`, `restore`), asynchronous reset/restore rebuilds, and the override commands (`set_override`, `clear_override`, `list_overrides`) are implemented.
- **Satisfies:** `REQ-017`; exercises the implemented `REQ-016` controls (lifecycle and speed) over the socket; overrides are deferred.
