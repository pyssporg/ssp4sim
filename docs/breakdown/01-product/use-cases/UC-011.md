# UC-011: Pause, Resume, and Stop a Simulation

- **Actor:** user controlling a running simulation.
- **Goal:** "pause, resume, or stop the running simulation to control execution interactively."
- **Outcome:** pause suspends execution at a macro-step boundary preserving simulation time and state; resume continues from the paused time; stop terminates, preserving results up to the last completed macro step and cleaning up FMU resources.
- **Capability:** interactive lifecycle control (`CP-001`).
- **Status:** implemented through `start`, `pause`, `resume`, `stop`, and `wait` on the C++, C, and Python surfaces.
- **Satisfies:** `REQ-016`.
- **Related:** `UC-026` covers the same commands through the external control surface.
